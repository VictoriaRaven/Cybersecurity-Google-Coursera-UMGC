# CMIT 265 – Fundamentals of Networking

## Course Overview

CMIT 265 introduces networking technologies and prepares students for the **CompTIA Network+ (N10-008 and N10-009)** certification exams.

The course covers:

- LAN, WAN, and wireless networking technologies.
- Network topologies, hardware, protocols, and connectivity.
- The OSI model and network architecture.
- Network installation, configuration, and troubleshooting.
- Network security devices and security best practices.
- Computer hardware, software, and system troubleshooting.
- Network infrastructure design and business requirements.
- Hands-on networking simulations and design proposals.
- IT safety procedures, professionalism, and technical documentation.

## Learning Objectives

Develop practical networking skills, understand network infrastructure, troubleshoot hardware and services, implement security measures, and design network solutions that meet organizational needs.
